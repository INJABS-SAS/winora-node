# Seguridad

Si encuentras una vulnerabilidad en el SDK o en la API de Winora, repórtala en
privado desde la pestaña **Security → Report a vulnerability** de este
repositorio. No abras un issue público.

Incluye la versión del SDK, los pasos para reproducirla y su impacto. No
incluyas llaves de API ni secretos reales.

Solo recibe parches la última versión publicada en npm.
